# Seal the Ocean

Небольшая игра в духе **Breakout / Arkanoid** с морской тематикой. Игрок управляет платформой, отбивает мяч, разрушает препятствия и проходит уровни, чтобы в финале спасти кита. Проект запускается на **HTML5 Canvas** и собран как модульное фронтенд-приложение без сторонних игровых движков.

## Что есть в проекте

- 3 уровня с разной сложностью + отдельный финальный уровнь с китом-боссом
- несколько типов блоков: обычные, усиленные, неразрушаемые и взрывные
- бонусы: широкая платформа, замедление мяча, дополнительная жизнь, бонус к очкам
- экран старта, пауза, game over, переходы между уровнями
- частицы, пузырьки, визуальные эффекты и простая звуковая система
- поддержка клавиатуры, мыши и touch-управления
- адаптация под мобильный экран и вертикальную ориентацию

## Технологии

- **JavaScript (ES modules)**
- **HTML5 Canvas 2D**
- **HTML / CSS**
- **Vite** для разработки и сборки
- **vite-plugin-singlefile** для сборки в один файл
- **ESLint + Prettier** для качества и форматирования кода
- **Husky + lint-staged** для pre-commit-проверок

## Структура проекта

```text
src/
  core/        # игровой цикл, state machine, рендер, масштабирование, input
  entities/    # мяч, платформа, блоки, босс
  systems/     # столкновения, бонусы, частицы, звук
  levels/      # конфигурация уровней
  ui/          # HUD, экраны, иконки, модальные окна
  debug/       # debug panel для разработки
  styles/      # стили страницы и canvas-обёртки
```

## Запуск проекта

```bash
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Полезные команды

```bash
npm run lint
npm run lint:fix
npm run format
npm run format:check
```

## Управление

- **← / A** — движение влево
- **→ / D** — движение вправо
- **Space** — запуск мяча / подтверждение действия
- **Esc / P** — пауза
- также поддерживаются **мышь** и **touch**
